# Hide in the Flock

Find the humans in the flock: you are a sheep hiding among ~100 AI sheep; the wolf gets three bites to eat only the humans. Built with [paprika3d](https://github.com/Keeno-Corp/paprika3d).

Live: https://hide-in-the-flock.pages.dev

On touch screens, drag the field to walk; hold Graze to eat clovers or Run to sprint. Mode switches to local play: drag the left half for the sheep and the right half for the wolf, hold Run to dash, and tap Bite to pounce. Restart starts a fresh round.
